
## 📌 Features

* Multiple choice questions
* Score calculation
* Instant correct/wrong feedback
* Final score display

## 🛠 Technologies Used

* Python 3

## 🚀 How to Run

1. Install Python
2. Download the project files
3. Open terminal in project folder
4. Run:

```bash
python quiz.py
```
